HOW TO CHANGE THE LOGO
======================

The logo is the file in this folder:  logo.svg

1. Put your logo here, named  logo.png  (or logo.svg / logo.jpg / logo.webp).
2. Delete the old logo file, so only ONE "logo" file is left in this folder.
3. Save and refresh the browser. The logo changes everywhere at once:
      - top menu bar
      - footer
      - intro screen
      - browser tab icon

Tips
- A SQUARE logo looks best (for example 512 x 512 pixels). PNG with a transparent background is ideal.
- If your logo already includes the business name, open  src\config\branding.js
  and set   showNameNextToLogo: false   so the name is not shown twice.
- Delete every file in this folder to go back to the built-in drawn "BM" moon logo.

The footer text (headings, email, address, copyright, notes) is changed in:
      src\config\branding.js
